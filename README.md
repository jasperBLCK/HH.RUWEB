# HH.RUWEB

Панель для поиска работы на hh.ru: подтягивает вакансии через официальное API, оценивает их под твоё резюме,
пишет персональное сопроводительное письмо и отправляет отклик — всё из одного окна.

## Возможности

- поиск вакансий по запросу с фильтрами из профиля (удалёнка, минимальная зарплата);
- сохранение полного описания вакансии в локальную БД (SQLite);
- скоринг 0–100 под профиль: LLM, а без ключа — по совпадению навыков;
- генерация сопроводительного письма под конкретную вакансию и компанию, с ручным редактированием;
- отклик через `POST /negotiations` с письмом и статусами (`new`/`applied`/`skipped`/`failed`).

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env    # заполнить ключи
uvicorn app.main:app --reload
```

Панель: http://localhost:8000

## Настройка

1. Создай приложение на https://dev.hh.ru/admin, укажи redirect uri `http://localhost:8000/auth/callback`,
   впиши `HH_CLIENT_ID` / `HH_CLIENT_SECRET` в `.env`. Либо вставь готовый `access_token` на странице «Профиль».
2. На странице «Профиль» заполни резюме, навыки, пожелания и `resume_id` (список доступен в `/api/resumes`).
3. На главной введи поисковый запрос, нажми «Найти», затем «Оценить все».
4. Для нужной вакансии сгенерируй письмо, при необходимости поправь текст и нажми «Откликнуться».

## API

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/search` | поиск и сохранение вакансий |
| POST | `/api/score/{id}` | оценка вакансии под профиль |
| POST | `/api/letter/{id}` | генерация письма |
| POST | `/api/letter/{id}/save` | сохранение отредактированного письма |
| POST | `/api/apply/{id}` | отклик с письмом |
| POST | `/api/skip/{id}` | пометить как пропущенную |
| GET | `/api/resumes` | список резюме аккаунта |

## Ограничения

- hh ограничивает частоту откликов: массовая отправка ловит капчу и временные блокировки, поэтому отклик
  отправляется по кнопке, а не автоматически пачками;
- часть вакансий требует ответов на вопросы работодателя — такие отклики API отклонит, их нужно отправлять на сайте;
- `api.hh.ru` может отдавать 403 за DDoS-Guard при запросах с дата-центровых IP.
